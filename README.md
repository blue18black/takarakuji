# takarakuji — ロト7 データ分析

ロト7の過去の当せんデータを機械学習で分析する。

1. **データ取得** — 第1回からの当せん番号・等級別の当せん金・当せん口数・キャリーオーバー
2. **バックテスト** — 「次回の当せん番号を予測するモデル」がランダムに勝てるかを検証
3. **被りにくい組み合わせの生成** — 当せん口数から各組み合わせの人気度を学習し、当たったときに山分けになりにくい組み合わせを選ぶ

## セットアップ

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

## 使い方

```powershell
.\.venv\Scripts\python.exe -m loto7 fetch        # 最新データを取得 (毎週の抽せん後に)
.\.venv\Scripts\python.exe -m loto7 backtest     # 予測モデル vs ランダム
.\.venv\Scripts\python.exe -m loto7 popularity   # 人気度モデルの学習・評価
.\.venv\Scripts\python.exe -m loto7 pick -n 5    # 被りにくい組み合わせを 5 口
```

## 結果 (第704回 2026-11-20 時点)

### 当せん番号は予測できない

直近404回を、各回それより前のデータだけで学習して予測した結果 (予測上位7個を1口として購入):

| モデル | 平均一致数 | 確率予測 (logloss) |
|---|---|---|
| 理論値 (ランダム) | 1.324 (偶然の範囲 1.232〜1.417) | — |
| 通算出現頻度 | 1.270 | ランダムより悪い |
| 直近20回のホット数字 | 1.344 | ランダムより悪い |
| ロジスティック回帰 | 1.322 | ランダムより悪い |
| ニューラルネット | 1.250 | ランダムより悪い |
| LSTM | 1.240 | ランダムより悪い |

どのモデルもランダムに選んだ場合の偶然の範囲に収まっている。数字ごとの出現回数もカイ二乗検定で一様 (p=0.81)。グラフは [reports/backtest.png](reports/backtest.png)。

### 人気度は学習できる

2〜6等は当せん者で賞金を山分けするので、`1口あたり当せん金 ∝ 売上 / 当せん口数` となり、
**当せん金が普段より高い回 = その回の当せん番号が不人気だった回** とわかる。
抽せんは完全ランダムなので、これは「人気度の実験データ」として使える。

- 3・4・5等の賞金の高低は互いに強く相関 (0.70〜0.90) → 共通する「人気度」がある
- 当せん番号の特徴から賞金の高低を予測: 未知データで R²=0.45 (リッジ回帰)

わかった傾向:

| 人気 (避けたい) | 不人気 (狙い目) |
|---|---|
| 1〜12 (月) の数字が多い | 32以上の数字が多い、合計が大きい |
| 1〜31 (誕生日) の数字が多い | 連番を含む |
| 7の倍数、奇数が多い | 同じ10の位に固まっている、間隔が大きく空いている |
| 8, 3, 7, 28, 27 | 20, 1, 16, 37, 21 |

`pick` は 30万通りのランダムな組み合わせをこのモデルで採点し、不人気度上位から選ぶ。
以下の組み合わせは除外する。

- 過去の当せん番号と同じもの
- 前回の当せん番号と3個以上重複するもの
- 特徴が過去データの範囲外 (外挿) になるもの

また、選んだ口どうしは共通数字を2個までにしている。

## 注意

- **当せん確率はどの組み合わせでも同じ** (1等 1/10,295,472)。このツールで変わるのは「当たったときの取り分」だけ。
- 宝くじの還元率は約45%。取り分が増えても、期待値は購入額を下回る。
- 取り分の推定は3〜5等 (7個中4〜6個一致) の口数から学習したもの。1等で山分けになるかどうかは7個全部の人気で決まり、効果はずれる可能性がある。
- データ元: [Chaos World](https://www.ne.jp/asahi/chaosworld/loto6/loto7dataf.html) (個人サイト)。取得は `fetch` 実行時のみ。公式の当せん番号は[みずほ銀行](https://www.mizuhobank.co.jp/takarakuji/check/loto/loto7/index.html)で確認すること。
- この PC では Windows のアプリケーション制御ポリシーが scikit-learn の DLL をブロックするため、使う機械学習の部品は numpy / scipy / PyTorch で実装している ([src/loto7/ml.py](src/loto7/ml.py))。
